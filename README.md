### Projeto de Análise de Vendas
Descrição do Projeto

Este projeto tem como objetivo analisar o dado de vendas, utilizando SQL e Python, para extrair insights de negócio e gerar relatórios gerenciais. O foco principal é entender o faturamento por produto, categoria, cliente, vendedor e período, além de identificar os produtos e categorias mais vendidos.

O projeto é dividido em três partes: SQL, Python e Insights de Negócio.
